# Portfolio Interactif - B.U.T. Informatique (Semestre 1)

[cite_start]Ce projet est un portfolio numérique interactif conçu pour le module de **Management et Gestion de Projet SI**[cite: 4, 5]. [cite_start]Il s'éloigne du format CV classique pour devenir une véritable "vitrine professionnelle"[cite: 118].

## 🚀 Concept : Le Système Solaire des Compétences
Plutôt qu'une liste statique, ce portfolio utilise une métaphore spatiale :
- [cite_start]**Le Soleil** : Identité professionnelle et accès au CV (format synthétique)[cite: 101].
- **Les Planètes** : Chaque planète représente une compétence majeure du référentiel B.U.T. (C1, C2, C3 pour le S1) [cite_start][cite: 112].
- **Les Orbites** : Symbolisent la progression et le cycle d'apprentissage.

## 🛠️ Structure Technique
[cite_start]Le projet suit une architecture modulaire pour garantir son **évolutivité**[cite: 39]:
- **HTML5/CSS3** : Structure sémantique et design immersif.
- **Animations CSS** : Gestion des rotations orbitales et des transitions de zoom.
- **JavaScript (Vanilla)** : Moteur d'interactivité gérant l'affichage dynamique des preuves.
- **Data-Driven** : Les contenus sont isolés dans `js/data.js` pour faciliter l'ajout de nouvelles compétences au semestre 2.

## 📋 Méthodologie de Justification
[cite_start]Conformément aux exigences pédagogiques[cite: 65], chaque compétence est prouvée selon la formule :
> [cite_start]**Preuve = Projet + Description + Rôle + Livrables** 

Chaque fiche projet inclut :
1. [cite_start]**Contexte** : Description précise du travail et des contraintes[cite: 67].
2. [cite_start]**Contribution** : Rôle exact au sein de l'équipe[cite: 68].
3. [cite_start]**Preuves Tangibles** : Liens vers le code, captures d'écran, schémas UML[cite: 81].
4. [cite_start]**Analyse Réflexive** : Retour critique sur les apprentissages et difficultés[cite: 111].
